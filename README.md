# Card Sharks website

A plain HTML and CSS website. No JavaScript, dependencies, or build step.

## Edit
- `index.html`: book description and deck details
- `author.html`: author page (biography pending)
- `contact.html`: contact page (public email pending)
- `styles.css`: shared layout and colors
- `assets/`: book cover and card back

## GitHub Pages
Push these files to the repository. In Settings → Pages, choose Deploy from a branch, then select your branch and the /(root) folder. All links are relative, so the site works at either a repository URL or a custom domain.

Add a custom domain in GitHub Pages settings when ready. No domain or email address has been assumed.
